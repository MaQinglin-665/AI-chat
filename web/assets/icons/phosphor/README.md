# Xinyu Phosphor icon subset

This directory contains the reusable SVG icons selected for Xinyu's anime-livestream interface.

- Source: https://github.com/phosphor-icons/core
- Weight: regular
- View box: 256 x 256
- License: MIT; see `LICENSE.txt`

The interface consumes these files as CSS masks so a single SVG can inherit night, day, hover, disabled, and selected-state colors without duplicating assets.
