# 馨语桌宠 v1.4.0-preview.7

本版改善网络故障反馈、说话动作与桌宠模式口型，并提供 DeepSeek 官方服务预设。

## 下载安装

Windows 10/11 用户下载 `Xinyu-AI-Desktop-Pet-Setup-v1.4.0-preview.7.exe`。
这是联网引导安装包，首次使用仍需联网准备依赖，自行配置 API Key 和有权使用的模型、声音素材。
开发者可下载 `Xinyu-AI-Desktop-Pet-v1.4.0-preview.7-windows-source-test.zip`。
用 `SHA256SUMS.txt` 核对文件；安装包未购买代码签名证书，系统可能显示未知发布者。

## 改进

- LLM 首数据等待、流式空闲与总时长分别受限；连接失败及时结束，不再整套重试非流式请求。
- 桌宠说话动作更丰富，表演随句子和播放生命周期停止。
- 聊天窗口隐藏时仍广播口型；扩大音量采样窗口，并按音频设备延迟补偿口型。
- 新安装默认连接 DeepSeek 官方 HTTPS 服务，模型为 `deepseek-flash`，使用非思考模式缩短等待。配置中心可选 DeepSeek；其他服务和旧配置继续可用。
- 前端按窗口需要加载 Live2D，开发面板按需加载；静态资源可重新验证缓存，日志轮转并减少正常断连噪音。
- 加强私人备份忽略规则，归档历史状态，固定直接 Python 依赖版本。

## API 配置

在配置中心选择 **DeepSeek official**，填写自己的 Key，或在本机 `.env` 设置 `DEEPSEEK_API_KEY`。
公开配置和发布包不含 Key、个人记忆、私人声音样本。已有私人配置不会被示例覆盖；升级后可在配置中心主动切换。
官方地址：`https://api.deepseek.com`；模型：`deepseek-flash`。
普通、流式、连通性探测和工具对话均关闭 DeepSeek 默认思考模式。
参数依据：[DeepSeek 官方文档](https://api-docs.deepseek.com/guides/thinking_mode/)。

## 验证与限制

- 最终代码：734 项 Python 测试、全部前端测试、口型专项测试、角色质量检查通过；首次启动打包检查通过，安装包及源码包已校验完整性和私人文件排除。
- 本机完成模型配置后启动预检通过。公开示例保留模型占位符，首次启动时需要选择模型。
- 三次独立官方流式请求首字为 4062 / 2109 / 2187 ms，中位数 2187 ms；分别收到 10 / 36 / 34 段正文。这是本机小样本测试，不是速度保证，也不包含 TTS 播放等待。
- 蓝牙、有线设备及最小化窗口的实际口型、动作效果尚需真人验收；未开启动态声音情绪指令。
- 直接依赖已固定，完整干净环境依赖安装尚未验证成功；本版仍为预览版。
