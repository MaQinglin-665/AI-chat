- 新增 `web/chatPolish.css`，由 `web/index.html` 最后加载；规则限定 `body.view-chat`，保持完整舞台、独立模型与 Galgame 的样式隔离。由于既有样式多处使用高优先级覆盖，本轮在一个明确文件中统一覆盖，避免改写多份历史主题。
