## 卡片与审批

标题按现有委派识别规则去除“帮我去做”“交给馨语去做”“帮我把”等前缀，再取短标题；完整服务目标摘要仅在正文出现一次。服务仅提供前160字符的goal_summary，不承诺恢复完整原输入。

| 状态 | 显示与主要操作 |
| --- | --- |
| 正在规划 | 等待计划，可取消；不能批准 |
| 待你审批 | 宽卡内联完整计划并审批；窄卡进入当前窗口详情 |
| 运行中 | 原地小跑、真实进度事件数；查看已批准的计划、取消 |
| 正在取消 | 等待服务清理，不表示已撤销文件变更 |
| 已结束 | 显示核对结果；没有异常才盖完成印章 |
| 未完成 | 吉祥物→粗体结论→一句原因；重新规划为主按钮 |
| 已取消 | 吉祥物→粗体结论→取消不会撤销已有变更；保留详情 |
| 计划已过期 | 从未批准，查看原计划；重新规划为主按钮 |
| 鉴权/连接错误 | 保留原计划和卡片，一处错误框列出说明；不自动重试审批或创建 |

“查看已批准的计划”只依据实际执行状态/核对数据或本会话成功审批响应；刷新后的失败/取消任务若没有批准证据，保守显示“查看原计划”。confirmation_id是待批阶段就有的字段，不作为批准证据。

卡片宽度低于约480px时，审批在同窗口详情完成，不修改Electron窗口。清单合计超过10项时，卡片只显示前5项及剩余数量，卡片DOM没有批准按钮，需在详情读完整清单后批准。窄详情的移动文件使用原路径一行、下一行“→ 文件夹图标 目标路径”。

删除、高风险、联网和错误不折叠隐藏。只有out_of_plan_count>0、planned_not_observed非空或verification_error时提示执行结果需要核对。任务卡片不进入聊天history、翻译、TTS或记忆；原narrator阶段播报不重复，刷新恢复静默。

不新增后端接口、权限、Origin规则、任务持久化或百分比进度。若需要这些能力，先由qinglinMa确认后端范围。原生CLI/DeepSeek验收按用户决定由作者电脑补做；本任务不自行合并。
