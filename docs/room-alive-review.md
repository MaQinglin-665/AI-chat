# 房间语音对话验收

源码版进入房间后，按住 T 说话，松开提交。输入框有焦点时保留打字。录音上限 12 秒。再次按住 T 会停掉当前播放并作废旧轮次的待播语句。按 M 沿用房间静音。语音识别复用本地 Paraformer 流式会话，识别为空时尝试现有整段 ASR。房间子进程只持有房间会话凭据。识别音频以 PCM 分块传给鉴权的本机服务。

模型每生成一个完整的台词对象，Godot 即可开始按句请求 TTS。涉及位置或动作承诺的行等终局动作校验。身体动作仍按原有白名单执行。情绪只取有限词表，通过 VRM 的表情预设绑定和头眼动作表现。人格与旧房间共享经过清理的历史和记忆上下文。

## 同题回归

基线 9194f8d。两侧各实际调用一次 deepseek-flash，使用相同合成题目和房间状态，第 2 题提供土豆传的上轮历史，第 16 题明确标记打断。以下是单次模型输出和开发者主观评语。自动回归使用这些固定样本检查分片、净化、标签和正文一致性；随机模型质量仍需试听。

## 费用估算

假定每轮 1,000 个未命中缓存的输入 token 和 160 个计费输出 token，按 Flash 每百万输入 $0.15–0.30、输出 $0.60–1.20 估计，40 次对比约 $0.0098–0.0197，8 轮演示约 $0.0020–0.0039。实际 token、缓存命中、时段及思考开销会改变金额，以上不是账单。Paraformer 和 Windows 本地 SAPI 无逐次 API 费用。[DeepSeek 官方价格](https://api-docs.deepseek.com/quick_start/pricing/)


## 三分钟实测

Godot 4.6.3，800×500，30fps H.264 + AAC。使用独立的 127.0.0.1 后端和每次随机生成的鉴权 token，远程生成使用 deepseek-flash。本机预热的 Paraformer 接收 16kHz PCM，中文 SAPI 播放用户问题和馨语回复。为了可复验，用八段合成语音送入同一个 PTT 采集总线，驱动与 T 键相同的按下/松开处理。没有把参考文字发送给对话接口。实际话筒和嘈杂现场尚待人测。

| 指标 | P50 / P90 |
| --- | --- |
| 松开到首个可听混音采样，含上下文短反应，8 轮 | 1.25s / 4.18s |
| 松开到正文，7 轮，剔除正文前被打断的一轮 | 3.75s / 4.55s |

P50 取中位数，P90 取最近秩。在这个样本上首声达成两秒目标。松开至首声逐轮毫秒为 [1485, 1006, 3749, 932, 605, 4180, 3397, 623]。不含首次下载或冷启动。第 3 次按下发生在上一句可听混音开始超过 900ms 后，旧音频停止，用户的新问题优先。上一轮的土豆书名在后续回复中得到延续，模型也把“土豆船”接成了划桨的梗。

完整转写可对齐的 7 句，去标点后共 77 个参考汉字、4 次字符编辑，CER 为 5.2%。第 2 轮打断未产生完整回合记录，不计入 CER。识别准确度来自受控合成语音，不能外推到答辩现场。
