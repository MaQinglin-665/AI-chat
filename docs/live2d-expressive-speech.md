# Live2D 台词与动作联动（2026-09-22）

本次针对 Hiyori 模型增强现有台词表演链路，不新增配置项、模型文件、TTS 服务或额外模型请求。

## 实际变化

- 保留逐句情绪提示中的细分语气，为俏皮、兴奋、害羞、难过、委屈、担心、生气、惊讶、认真和思考等提供不同的头部、躯干、肩膀与手臂姿态。不再让害羞、兴奋、俏皮在持续说话时只有同一种开心身体基调。
- 利用现有语音音量的快速/慢速包络差检测声音起伏，触发平滑点头、肩部和手臂强调。强调最短间隔 680ms，持续大音量不会反复触发。
- 检测到真实音量后，静音停顿会压低持续身体节奏；已有语义姿态可保留到句子结束。安慰、难过、害羞等语气使用更柔和的强调。
- 尊重原有 low/normal/high 动作幅度。已有 motion3 大动作继续优先，新增参数层在大动作期间降低权重；不抢占嘴型和眨眼。
- 等待 TTS、仅有表演提示时不生成新增语音强调；结束/打断时清理检测器并通过现有惯性平滑回落。其他模型保持现有行为。

这里的“重音”是音量上升检测，不是词级强制对齐或语言学重音识别。语义效果依赖已有台词情绪提示的正确性。Browser TTS 等没有音量分析数据的路径只保留原有节奏兜底与语义姿态，不虚构音量重音。
