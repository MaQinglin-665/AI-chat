## 真实 Electron / CLI / DeepSeek

使用现有 Electron 39.8.10 独立验收窗口，加载本分支真实页面、真实 Python 服务与真实 CLI 0.164.0 / DeepSeek。运行目录、CODEX_HOME、记忆和审计均隔离在仓库之外；Key 仅从既有环境变量读取。全局 CLI 和用户自身 Codex 配置未修改。

这是实际 Electron renderer、页面交互、HTTP 后端和模型调用的联调。为不干扰用户日常实例，验收使用独立启动器和端口，没有覆盖生产 main/preload 的全部桌面 IPC，也不是安装包发布验收。

| 场景 | 实测结果 |
| --- | --- |
| 聊天输入委托 | 打开任务表单；未点击生成前，后端任务数为 0 |
| 只读规划与拒绝 | 生成计划后点拒绝，状态 cancelled；两个源文件仍保持原样 |
| 文件整理 | 用户界面生成计划、查看完整清单、点批准；规划约 31 秒，执行约 47 秒，22 个进度事件、0 警告 |
| 实际结果 | `alpha.txt` → `txt/alpha.txt`，`beta.csv` → `csv/beta.csv`；两个目标目录及两个文件新增、两个源路径消失；内容检查保持一致 |
| 计划核对 | out_of_plan 为 0，未观察到的计划项为 0；共同经历摘要写入成功 |
| 运行中取消 | 真实计划批准后，每秒向 `cancel-heartbeat.txt` 追加整数，原定运行 120 秒；在写入过程中点击取消，状态 cancelled |

整理任务的规划、待批准、执行、完成语音均捕获到真实播放器开始和结束事件，时长约 4.83、9.70、4.67、6.30 秒。用户明确反馈规划和确认提示“听到了，清楚”。完成及取消播报有播放器事件证据，但没有另行要求用户逐句听评。未将播放器事件等同于所有语音场景的听感保证。

首轮模型把重命名描述写成文件路径（如 `a -> b`），已拒绝该计划并修复路径约束及规划提示，之后重新生成并通过真实整理任务。完整 commands 数组按原样展示；模型有时返回自然语言操作描述，它不是命令级强制许可清单。

## 限制

元数据比对不能发现大小和修改时间均未变化的内容修改；外部并发写入可能计入差异。扫描不跟随链接，但不是文件系统事务快照。它是事后核对，不会回滚变更，也不能约束任意生成命令的全部副作用。

Windows unelevated 写入验证不代表完整读取隔离；仅适用于可信、独占的测试工作目录。默认仍关闭；需要显式配置授权目录。只支持按钮批准，语音批准未接入；任务和原始文件清单没有跨服务重启恢复。其他 CLI 版本、其他 TTS 提供商和生产打包启动仍需各自验收。
