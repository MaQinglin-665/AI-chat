## 镜头：原有问题与本次接入问题分开

### 原有问题，本次不修

在旧录像 7:45 附近扩大范围抽帧，约 7:50 出现只剩墙面；角色目标并非丢失，镜头在活动切换时穿出左墙。

原因是切换到书架时立即采用书架的相对机位 offset.x=-3.5，但人物仍在沙发附近 x≈-1.22，因此平滑目标暂时在 x≈-4.72。临界阻尼平滑不能替代墙体碰撞约束。

5:15 附近可见椅子处于前景/移动路线视线上。既有镜头代码没有家具遮挡检测或回避，只对水平根位置做死区和平滑。
0:45 的近景沿用现有陪伴机位、视场角与距离；这些参数未被本 PR 修改。原镜头不跟随骨骼起伏，转身不是这次目标丢失的证据。
以上记录为后续镜头任务：限制机位在室内、在路径转场保持可见性、增加家具遮挡回避、重新验收陪伴近景。不在本 PR 扩大修改。

### 本 PR 接入边界，已修

新增 go_to 允许只抵达座位而不进入坐姿，但原镜头看见活动名 rest/desk 就按坐姿计算目标：人物仍站在活动点，却把镜头对准座位臀部位置和坐姿高度。
世界状态现在显式带 poseEnabled；go_to 禁用姿势时，镜头继续对准站立根位置。sit/activity 启用姿势后才使用原坐点；机位锁定键也区分站立/姿势，确保同一个活动点从 go_to 切到 sit 时能重新平滑构图，而不会继续锁住站立目标。旧随机日常缺省行为保持不变。
