# 新卧室中的自主行为

Godot 4.6.3，Windows，真实 DeepSeek Flash。用户侧按固定路线活动，房间角色通过正式的意图接口、本地调度和导航自主行动。美术模块来自 #240；本阶段修改宿主的交互、角色、相机和聊天接线。

## 座位和镜头

第二阶段用户坐在沙发物件中心，角色根据用户位置单独加横向偏移；两人没有采用同一个座位朝向。入座不校正用户的视线，验收相机还会一直指向角色。旧画面容易正对身体。现有证据不能证明旧相机穿进了网格。[修复前第一人称](docs/phase2/06-adjacent-seat.png)

宿主现在从 14 个 Interaction Marker 读取稳定 ID、能力和 Approach。可坐物件额外读取 Seat 的世界变换，局部 +Z 为前向。沙发只有一个中心 Seat，宿主从碰撞包络宽度推算左右坐垫；单人椅按占用情况拒绝重复入座。坐姿动画稳定后，对齐模型髋骨与座面。第一人称视点留在用户胶囊水平中心，近裁剪为 8 厘米。用户坐下后能单独转头，不会扭转整个身体。第三人称沿用碰撞收缩的越肩相机。

## 房间行为与聊天

- 灯光跟随本地时段，5–17 时使用白天（含清晨），17–20 时为黄昏，其余为夜间，与桌宠自动时段对应。第三人称访客是 CC0 的 Vita，馨语仍为千驮谷筱。[访客来源与许可](README.md)
- 一分钟内去过的地点在下一次自主决策中的建议权重降到 0.2，其他地点为 1。用户命令不加惩罚。本地独处行为可选择去书桌椅坐下、去书架前看书或去窗边看景。看书使用注视和停留。角色已在舒适距离内时，本地亲近行为只转向注视。
- 房间状态优先报告实际占用的座位。若同坐状态已经满足，再确认座位不会让角色站起来走一圈。气泡按字数计时，支持换行；房间聊天接收已有流式接口，等完整 UTF-8 事件再更新气泡。括号旁白在显示前过滤，也从最终的房间回复移除。
- 可用启动器的 `--phase3-tour` 重放用户路线。录制从独立的 960 × 540 视口取帧，不依赖窗口是否被遮挡。录制脚本只移动用户；单人椅若被占用，用户会先用聊天提出让座请求。录像保存在本机忽略目录 `tmp_ui_smoke/godot-room-phase3-deepseek-30fps.mp4`。

## 真实 DeepSeek 连续 305 秒

自主决定 10 次，首动作 为前往地点 7 次、注视 1 次、待机 2 次。其中 6/10 次保持安静（60.0%），另有 4 次伴随说话。用户请求及本地小动作均排除在上述分母之外。

| 多步目标来源 | 已完成 / 接受 | 其他终态 |
|---|---|---|
| user | 2/2 | 无 |
| autonomous | 9/10 | 1 次被用户的新指令打断 |
| utility | 2/2 | 无 |

| 延迟指标 | P50 / P90 |
|---|---|
| 意图完整往返（12 次） | 2.36 / 3.50 秒 |
| 房间上下文构建（同机 500 次单独测量） | 0.01 / 0.01 毫秒 |
| 真实聊天请求进入后端到发往上游（含组装上下文等准备） | 23.50 / 30.30 毫秒 |
| 上游聊天首字 | 1.93 / 2.15 秒 |
| 聊天请求到首个可见气泡文字 | 1.98 / 2.20 秒 |
| 聊天请求到完整气泡 | 2.22 / 2.54 秒 |
| 用户按下发送到完整气泡（含先获取身体意图） | 5.03 / 5.84 秒 |

聊天用了已有的鉴权流式接口；只在拿到动作意图后才发送实际房间状态。首字与完整回复分别测量。小样本线性插值的分位数不能代表长期尾延迟。

按供应商返回用量，意图 12 次、聊天 2 次，合计 11478 token（缓存命中 2688、未命中 8075、输出 715）。按 Flash 非高峰价估算，本次 US$0.00165，同频率约 US$0.0195/小时；高峰单价为两倍。[官方价格](https://api-docs.deepseek.com/quick_start/pricing/)

## 验收结论与遗留问题

- 入门后，用户保持位置超过一分钟；1:32 坐沙发，1:41 请求同坐，两种视角都拍到相邻坐垫；2:45 请求看窗外；3:24 起身、3:28 在书桌前坐下，4:26 再起身走到房间另一角。按同一会话的回执，两条用户多步指令均完成。房间回复未出现括号动作旁白。模型从收到用户请求到生成回复时，身体仍可能继续前进，因此文字与动画之间仍有时间差。
- 安静占比 60%。这段录像内仅观察了 10 个自主决定，不能据此保证每次运行都在 40%–60%。首选目标两次都是书架，中间在书桌坐过；降权仍保留重复去同一地点的可能。一次本地单步接近用户收到 unreachable，未计入多步目标成功率。
- 从用户按下发送到完整气泡的 P50 为 **5.03 秒**，超过 3.5 秒目标。聊天请求本身的 P50 为 **2.22 秒**。主要等待来自先拿到动作决定，再基于已接下的目标发起聊天，两次上游调用串行。本次两条聊天不足以稳定估计 P90。
- 画面对照显示两人不再面对面贴近；右坐垫前方的搭毯仍会遮住部分小腿，沙发只有一个中心 Seat，床没有 Seat。此处记录给美术作者。邻座间距是宿主根据两人沙发的宽度推算的，不宜直接用于未来不等宽或非对称座位。
- 完整录像已解码检查，960 × 540、30 fps、305.000 秒、9,150 帧。13 个丢失的 30 Hz 采样点沿用最近画面。前期调试曾遇到流式连接过早结束和窗口被遮挡后录到旧画面，以上数字、账单和关键帧全部取自修复后的同一轮。
- 完整本地检查通过：1,113 项 Python 测试通过、3 项跳过，86 组 Node 测试通过，语法与秘密扫描通过。Godot 额外验证了导航、占座、重复同坐、两种相机和动画网格净距。定向测试退出时仍出现引擎资源清理告警，单次用例无法判断长期内存趋势。
