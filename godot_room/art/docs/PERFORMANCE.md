# 性能和资源预算

2026-11-01，本机AMD Ryzen9 8940HX / 32逻辑核，RTX5060 Laptop + Radeon610M；Windows，Godot4.6.3 official7d41c59c4。只在离线独立美术场景加载1个公开CC0千驮谷筱及原上游Idle/次级动画，无bridge、LLM、网络或录屏。关闭垂直同步，屏幕外真实Vulkan绘制，240帧预热后各测12秒。低档为关闭本模块主光阴影、960×540/MSAA关闭；balanced为1280×720/2×MSAA/柔化主光阴影。

FPS按真实采样帧数/帧时间总和计算，不用1000/中位帧时间冒充平均值。CPU渲染时间为viewport CPU渲染+frame setup，未包含脚本/物理全部耗时；进程CPU另外用Windows GetProcessTimes测Godot实际渲染子进程，并除以32逻辑核。console启动器几乎不耗CPU，已排除其0%假样本。GPU为RenderingServer实际渲染毫秒，不是全机GPU百分比。

独显场景高于60fps预算。弱集显默认档平均约40fps、个别长帧会降低平均值；需要Mobile低开销档才能留出充足余量。没有隐瞒画质差异，也没有把低档数据当成默认档。最终Electron窗口、双角色/自主行为/后端活动与长时间热功耗不是这次短测范围，由主线集成后复测；不声称所有独显/集显均保证60fps。原始逐帧数据/日志留在仓库外，仅提交本简报。

实际渲染统计：独显balanced约348次draw call、300144个绘制三角形；集显Mobile balanced约775次、300540三角形；low约335次、132742三角形。统计包含阴影等pass，不能按它推算唯一模型面数。点光不投影，无SSAO、体积雾或新每帧美术计时器。

## 体积

新美术使用程序几何、共享材质和2个短着色器，**新增贴图0张**。8张PNG是验收截图，不是运行纹理；docs有.gdignore，不参与Godot资源导入。总新增art文件约4MB（实际字节索引见截图清单），低于30MB预算。模型和动画均沿用spike，不新增/修改；已读公开Shino嵌入图像尺寸，最大2048×2048。

## 验证

art/tools/verify.gd：43个实际烘焙多边形，14个Marker接近点从入口连通，沿每段0.15m步长做半径0.30m/高1.65m胶囊碰撞检查，共584次，无家具穿透；接近点水平吸附偏差≤0.10m，垂直约0.2m为烘焙栅格结果。

既有check_navigation：实际走到椅子并进入Sitting_Idle，起身回Idle。角色/行为/后端脚本未改。导入仍有spike已记录的vrm/already_processed字典键诊断，公开模型和动画导入成功；不改第三方插件掩盖该问题。完整本地/CI结果见PR说明与本目录交接。
