# 安静的房间声音

city.wav（16秒、单声道22050Hz）、air.wav（8秒）、lamp-click.wav（0.12秒）均由 [generate_audio.py](../tools/generate_audio.py) 原创合成，无真人录音、音乐或第三方采样，按本模块 [CC0 1.0](../LICENSE-CC0.txt) 提供。来源就是本仓库生成器，作者为本贡献（AI辅助，qinglinMa维护）。城市声是低通噪声和远处车流般起伏的合成氛围，不声称实地采集。

城市声默认-35dB（白天-41dB），空调-44dB；台灯点击-28dB且只由L键触发。两个氛围流循环，边缘短淡入淡出。QA必须设置 XINYU_ART_MUTE=1；镜面视口不启用音频监听器。没有额外下载、麦克风、语音、后端连接。实际响度仍取决于系统音量；本次验收静音，仅检查波形、循环和增益。
